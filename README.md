# Handwritten Character Recognition

## Objective
Identify handwritten digits using Deep Learning.

## Dataset
MNIST Dataset

## Model
Convolutional Neural Network (CNN)

## Tools Used
- Python
- TensorFlow
- Keras
- Google Colab

## Preprocessing
- Normalization
- Image Reshaping

## Results
- Training Accuracy: 99.47%
- Validation Accuracy: 99.09%
- Test Accuracy: 99.09%

## Outcome
Successfully built a CNN model that recognizes handwritten digits with high accuracy.
